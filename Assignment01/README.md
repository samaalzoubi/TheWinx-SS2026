## Task 2: Select Application Scenario

As required, the team proposed two preferred application scenarios from `01a - Application Scenarios`. The department assigned:

> **Scenario 4: Instant Mobility Platform**

The platform aggregates multiple vehicle-sharing providers (e-scooters, bicycles, e-bikes, electric cars) into a single application, letting users search, book, ride, and pay across providers, while providers manage their fleets, pricing, and usage restrictions. This scenario is binding for the remainder of the project.
