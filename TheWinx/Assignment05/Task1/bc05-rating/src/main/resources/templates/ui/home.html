Rating Service

Collects vehicle & provider feedback after a completed ride.

What would you like to do?

Submit a rating

Browse all ratings

Look up by vehicle / provider

Example: ratings for vehicle 1

REST API surface

This UI is a thin layer over the same REST API used by other services and the gateway:

  • POST /api/ratings
  • GET /api/ratings/{id}
  • GET /api/ratings/booking/{bookingId}
  • GET /api/ratings/vehicle/{vehicleId}
  • GET /api/ratings/provider/{providerId}
  • GET /api/ratings/vehicle/{vehicleId}/average

Example bookings available in the mock BookingClient: 5001 & 5002 (COMPLETED – rating allowed), 5003 (ACTIVE – rejected with 409). These are also used as the standalone circuit-breaker fallback when bc03-booking is unavailable.
